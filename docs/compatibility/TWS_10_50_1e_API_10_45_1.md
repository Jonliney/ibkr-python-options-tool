- successful connection and server-time response;
- `readOnlyApi=true` and `allowLocalhostOnly=true` from TWS configuration;
- completed position and open-order snapshots;

- a quote snapshot and market rule;

binding, or global-cancel request. In particular, it did not call
`reqOpenOrders()` or `reqAutoOpenOrders()`.

## Scope and limitations

This proves the read-only capability and coherent-snapshot contracts for one
paper-TWS session. It does not validate live order behavior, order submission,
cancellation, partial fills, stop triggering, or complex-order handling. A
later TWS or API upgrade invalidates this evidence until both checks are rerun.

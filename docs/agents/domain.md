# Domain docs

This is a single-context repository.

Before exploring or changing the domain, read `CONTEXT.md` at the repository
root when it exists and any relevant decisions under `docs/adr/`. If those
files do not exist, proceed without creating them pre-emptively.

Use the domain vocabulary defined in `CONTEXT.md`. If work would contradict an
existing architectural decision, surface the conflict explicitly instead of
silently overriding it.
